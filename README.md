# SMMWay AutoSync для FunPayCardinal
> **Работает в связке с SMM-автовыдачей от @fendi_tt и @dxvxlz**

Автоматический пересчёт и синхронизация цен лотов FunPay с сервисом накрутки **SMMWay** (с любым смм прокатит) по API v2

---

### Особенность пересчёта цен 
Плагин работает **только на повышение цены**:
* Если поставщик поднял цену $\rightarrow$ плагин автоматически пересчитывает и поднимает цену на FunPay, чтобы вы не продавали в минус.
* **Цена никогда не опускается вниз автоматически.** Если вы вручную поставили цену выше расчетной или у поставщика упала себестоимость — ваша установленная цена останется на месте.
